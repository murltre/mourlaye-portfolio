# Mourlaye Traore — Portfolio

A one-page Data Engineering portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before publishing

Update the placeholder contact links in `src/main.jsx`:
- `YOUR_EMAIL@example.com`
- LinkedIn URL
- GitHub URL

Then push the folder to GitHub and connect the repository to Netlify.
